## What
The admin wears benrey.io's design language:
- a near-black, dark-only ground;
- one acid-lime accent;
- wide oblique display headings;
- uppercase Geist Mono for everything functional (labels, table headers, breadcrumb, buttons);
- cards edged with a conic-gradient border.

The tokens were measured from benrey.io on 2026-10-15. The full capture (a DESIGN.md with screenshots, plus a static rebuild of the homepage) lives outside this repo, at `C:\Users\Aleksei\Software\Projects\design-lab\benrey.io\`.

## Why
The project is a take-home for Benrey, so the UI speaks their visual language.

It is applied **through Unfold's own settings plus one stylesheet**, not custom templates, so the admin is still generated by Django's tooling (see [admin-ui.md](admin-ui.md)).

**Rejected:**
- **Overriding Unfold templates:** every Unfold upgrade (it releases weekly) would need a merge.
- **A light-mode variant:** Benrey is dark only, and a second palette would double the review surface.
- **Self-hosting the fonts:** more files for no gain until the Phase 5 CSP work decides on font hosting.
- **Benrey's own logo, 3D renders and licensed Base Neue font:** they're the brand's assets. Only the language is borrowed.

## How it's set up
- **`UNFOLD["THEME"] = "dark"`** forces dark mode and hides the theme switch.
- **`UNFOLD["COLORS"]`:**
  - **`base` ramp.** Unfold paints the dark page with `900` and borders with `800`/`700`:
    - 900 #060606 ink black (page);
    - 800 #232523 hairline;
    - 700 #3c3c3c divider;
    - 300 #b8b9b6 body text;
    - 100 #ebeceb headings.
  - **`primary` ramp:**
    - 600 #c3ff00 lime signal (button fills);
    - 500 #cbfb2e lime ink (dark-mode text accents);
    - 400 #dbff66 hover.
- **`UNFOLD["STYLES"]`** loads two stylesheets:
  - the Google Fonts CSS;
  - `core/theme.css`, which carries what the ramps can't:
    - fonts;
    - lime buttons with near-black text;
    - lime caption-style fieldset headings;
    - mono labels;
    - the conic card edge;
    - lime `accent-color`;
    - a 0.5 s fade-up on load (off under `prefers-reduced-motion`).
- **Display face:** Archivo at `font-stretch: 125%`, weight 800, italic. It stands in for Base Neue Wide.
- **Test:** `tests/test_admin_theme.py` checks the login page is dark, carries the lime variable, and loads the fonts and `theme.css`.

**Source tokens, for future screens:**
- radius 8 px (12 px for CTA cards);
- card padding 32 × 24 px;
- caption: 14 px uppercase mono lime with an 8 px square bullet;
- buttons: 52 px tall, `4px 18px` padding;
- motion eases: `cubic-bezier(.25,.46,.45,.94)` for UI, `.215,.61,.355,1` for reveals.

## Gotchas
- **`STYLES` load before Unfold's own CSS.** `theme.css` still wins because Unfold's Tailwind rules sit in cascade layers and this file is unlayered. Don't wrap it in `@layer`.
- **Unfold renders hex colours as `rgb()`** in its `--color-*` variables. Assert on `rgb(195, 255, 0)`, not `#c3ff00`.
- **White text on lime is unreadable.** Unfold's buttons ship `text-white` on `bg-primary-600`, so `theme.css` forces #0c0c0c there. Any new component on a lime fill needs dark text too.
- **The fonts come from fonts.googleapis.com / fonts.gstatic.com.** The Phase 5 CSP must allow both (`style-src`, `font-src`), or self-host them.
- **Stock `User`/`Group` pages** keep Django's fieldset heading markup until they're re-registered with Unfold's admin classes (Phase 1 in [admin-ui.md](admin-ui.md)).
