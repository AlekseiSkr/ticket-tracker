## What
The whole UI is Django's built-in admin, configured through `ModelAdmin`, with the Unfold
theme for a modern look: dark mode, badges, dialog actions, autocomplete filters and
dashboard components.

## Why
The brief requires the admin to be generated by the framework's own tooling rather than
hand-built. Django's admin has true inline formsets, permission-aware actions and
per-request field hooks (`get_fields`, `get_readonly_fields` …) for visible role
restrictions. Unfold is a skin on top of these, not a replacement.

**Rejected:**
- **Stock admin look:** works, but looks dated to a non-technical reviewer.
- **Jazzmin:** 175 open issues, including inline and dark-mode bugs.
- **Grappelli:** no dark mode.
- **django-jet-reboot:** AGPL and stale.
- **Payload CMS / a Next.js admin:** dropped on 2026-10-15. Its related-records drawer isn't
  true inline editing, and it was 35–40% more work.

## How it's set up
- `unfold` and `unfold.contrib.filters` go **before** `django.contrib.admin` in
  `INSTALLED_APPS`.
- Pinned exactly (`django-unfold==0.110.0`) because it's 0.x and releases weekly.
- Core behaviour (actions, inlines, permissions) uses **stock Django APIs**, so removing
  Unfold is a mixin swap.
- The look (dark only, lime accent, wide oblique headings) is set through `UNFOLD`
  (`THEME`, `COLORS`, `STYLES`) plus `core/static/core/theme.css`. See
  [design-language.md](design-language.md).

## Gotchas
- **Unfold's base template has no `extrabody` block** (verified 2026-10-15 on `main`).
  Mount the AI chat with `change_form_outer_after_template` or `UNFOLD["SCRIPTS"]`.
- **Custom `UNFOLD["SIDEBAR"]` items are visible by default.** Every custom item needs a
  `permission` callback, or keep the auto-generated, permission-aware sidebar.
- **`User` and `Group` are re-registered with Unfold's admin classes** in `core/admin.py`.
  Without that they render in the stock style. Phase 1 role restrictions extend those classes.
- **Don't enable `UNFOLD["COMMAND"]["search_models"]`.** It lists `str(obj)` for every searchable
  model, which would bypass per-role field hiding.
- **Tests run with `DEBUG=False`**, so they use plain static storage
  (`tests/conftest.py`). The manifest storage would fail without `collectstatic`.
