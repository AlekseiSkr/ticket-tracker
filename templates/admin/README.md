## What
Each file extends Unfold's template of the same name (Django's recursive `{% extends %}`
resolves to the next loader) and overrides one block.

## Why
The admin must stay generated by Django's tooling. These add accessibility and orientation
without replacing any Unfold markup.

**Rejected:** `admin/base_site.html` for the skip link. Unfold's dashboard extends
`admin/base.html` directly, so a skip link in `base_site.html` never reaches it.

## How it's set up
| File | Adds |
|---|---|
| `base.html` | "Skip to main content" as the first focusable element on every admin page. |
| `index.html` | The dashboard greeting ("Welcome back, {name}.") and today's date above Unfold's app list. |
| `change_form.html` | The AI form assistant panel (block `form_after`) on every add and change page; `core/static/core/assistant.js` drives it. The field list is rendered from the admin form and its inlines, so read-only, disabled and dropdown (select2) fields are listed even though they can't be focused. |

## Who owns what

## Gotchas
- **Extending the same template name only works because the project `DIRS` comes before the app loaders.** Don't move these into an app's `templates/`.
